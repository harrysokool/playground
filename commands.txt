## 2. Education level description

Table: gold_agent_education

Create or update a reusable Field named "Education level description".

Use the verified Unity Catalog metadata:

01 = College/University
02 = Vocational Education Institution
03 = Secondary School

Source: aa_tbleducation.TXTEDULEVELCD

SQL:

CASE
  WHEN `gold_agent_education`.`agt_edu_level_code` = '01' THEN 'College/University'
  WHEN `gold_agent_education`.`agt_edu_level_code` = '02' THEN 'Vocational Education Institution'
  WHEN `gold_agent_education`.`agt_edu_level_code` = '03' THEN 'Secondary School'
  WHEN `gold_agent_education`.`agt_edu_level_code` IS NULL THEN 'Not recorded'
  ELSE CONCAT('Unknown code: ', `gold_agent_education`.`agt_edu_level_code`)
END

Do not invent meanings for unknown codes.
