Review and audit the entire Examples tab of my existing Genie Agent, "Agent Master and Licensing Analytics".

The Examples tab contains five configuration types:

1. Example Queries
2. Filters
3. Measures
4. Fields
5. Joins

Our goal is to simplify the configuration by removing unnecessary duplication while preserving useful business knowledge and SQL accuracy.

First, read every existing item across all five types.

TASK 1: Identify redundancy

Identify:

1. Exact duplicates with identical business purposes and SQL logic.
2. Different items that answer essentially the same question.
3. Filters that overlap unnecessarily.
4. Measures that calculate the same business metric under different names.
5. Example Queries that teach the same SQL pattern without adding meaningful value.
6. Fields that duplicate existing calculations.
7. Joins that overlap or conflict.

Do not automatically consider two items redundant just because they use similar SQL.

For example, a Filter defining active Agency agents and a Measure counting active Agency agents serve different purposes and may both be useful.

TASK 2: Evaluate usefulness

For every item, decide whether to:

KEEP: Provides useful, distinct knowledge.

REMOVE: Redundant and adds no meaningful value.

MERGE: Several items could be replaced by one clearer item.

CORRECT: Contains outdated or inconsistent business logic.

Consider how likely business users are to ask the questions and whether the item helps Genie generate accurate SQL.

Preserve important distinctions between Agency agents, PD firms, technical representative records, licence records, licence types, and education records.

TASK 3: Check dependencies

Before recommending deletion, check whether each item is referenced or relied upon by:

1. Other Examples configurations.
2. General Instructions.
3. About suggested questions.
4. Benchmarks.
5. Important business calculations.

Do not recommend removing something if it would leave important business logic unsupported.

TASK 4: Review configuration quality

Evaluate whether the current Examples configuration follows Azure Databricks Genie best practices.

Look for:

1. Unnecessary complexity.
2. Repeated SQL logic that provides no additional teaching value.
3. Conflicting definitions.
4. Excessively specific examples that do not generalize well.
5. Missing examples for important business questions.

Prefer a smaller, clear, accurate configuration over a large collection of repetitive examples.

TASK 5: Produce a cleanup proposal

Provide:

1. Current number of items in each of the five categories.
2. Items recommended to KEEP.
3. Items recommended to REMOVE, with exact names and reasons.
4. Items recommended to MERGE, explaining what should replace them.
5. Items recommended to CORRECT.
6. Any dependencies or risks associated with the proposed changes.
7. Estimated number of items remaining after cleanup.

For each recommendation, clearly explain why it would improve the Genie Agent.

IMPORTANT:

This is an audit only.

Do not delete, rename, merge, or modify anything yet.

Do not modify other configuration sections or underlying data.

If SQL compute is unavailable, inspect the saved SQL and metadata without claiming that queries were successfully tested.

Return a detailed cleanup proposal for my review before making any changes.
