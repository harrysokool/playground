*Q1. How many active Agency agents are there?* (reference: 20,431)
```sql
-- Active (in-force) Agency agents: status codes 00 and 10. Counts unique agents.
SELECT
  COUNT(DISTINCT `m`.`INTAGTSEQ`) AS `active_agency_agent_count`
FROM `aiahk_dna_p_catalog`.`dna_gia_base`.`gold_agent_master` AS `m`
WHERE `m`.`row_type` = 'Agency'
  AND `m`.`agent_status_code` IN ('00', '10')
```

*Q3. How many Agency agents are there by region and distribution channel?* (reference total: 142,857)
```sql
-- All Agency agents regardless of status. Each agent has one master record, so group counts add up to the total.
SELECT
  COALESCE(`m`.`region`, 'Unknown') AS `region`,
  COALESCE(`m`.`agent_channel`, 'Unknown') AS `agent_channel`,
  COUNT(DISTINCT `m`.`INTAGTSEQ`) AS `agency_agent_count`
FROM `aiahk_dna_p_catalog`.`dna_gia_base`.`gold_agent_master` AS `m`
WHERE `m`.`row_type` = 'Agency'
GROUP BY
  COALESCE(`m`.`region`, 'Unknown'),
  COALESCE(`m`.`agent_channel`, 'Unknown')
ORDER BY
  `region`,
  `agency_agent_count` DESC
```

*Q4. How many active Agency agents have at least one currently effective licence record?* (reference: 20,400)
```sql
-- Currently effective = typed licence record whose effective period includes today.
-- Effective dates do not prove regulatory authorization: licence records also include training,
-- certifications, sales eligibility and restriction records.
-- EXISTS prevents agents being multiplied by multiple licence records.
SELECT
  COUNT(DISTINCT `m`.`INTAGTSEQ`) AS `active_agents_with_effective_licence_record`
FROM `aiahk_dna_p_catalog`.`dna_gia_base`.`gold_agent_master` AS `m`
WHERE `m`.`row_type` = 'Agency'
  AND `m`.`agent_status_code` IN ('00', '10')
  AND EXISTS (
    SELECT 1
    FROM `aiahk_dna_p_catalog`.`dna_gia_base`.`gold_agent_license` AS `l`
    WHERE `l`.`INTAGTSEQ` = `m`.`INTAGTSEQ`
      AND `l`.`row_type` = `m`.`row_type`
      AND `l`.`license_type` IS NOT NULL
      AND `l`.`license_eff_date` IS NOT NULL
      AND `l`.`license_exp_date` IS NOT NULL
      AND `l`.`license_eff_date` <= CURRENT_DATE()
      AND `l`.`license_exp_date` >= CURRENT_DATE()
  )
```

*Q6. How many active PD firms have no currently effective licence records?* (reference: 377)

      AND `l`.`license_eff_date` IS NOT NULL

      AND `l`.`license_exp_date` >= CURRENT_DATE()

*Q7. How many Agency agents are there by education level?*
```sql
-- Level labels come from Unity Catalog metadata (aa_tbleducation.TXTEDULEVELCD).
-- An agent can hold several education levels, so level counts overlap and must not be summed to get unique agents.
SELECT
  CASE
    WHEN `e`.`agt_edu_level_code` = '01' THEN 'College/University'
    WHEN `e`.`agt_edu_level_code` = '02' THEN 'Vocational Education Institution'
    WHEN `e`.`agt_edu_level_code` = '03' THEN 'Secondary School'
    WHEN `e`.`agt_edu_level_code` IS NULL THEN 'Not recorded'
    ELSE CONCAT('Unknown code: ', `e`.`agt_edu_level_code`)
  END AS `education_level`,
  COUNT(DISTINCT `e`.`INTAGTSEQ`) AS `agency_agent_count`
FROM `aiahk_dna_p_catalog`.`dna_gia_base`.`gold_agent_education` AS `e`
JOIN `aiahk_dna_p_catalog`.`dna_gia_base`.`gold_agent_master` AS `m`
  ON `m`.`INTAGTSEQ` = `e`.`INTAGTSEQ`
  AND `m`.`row_type` = 'Agency'
GROUP BY 1
ORDER BY `agency_agent_count` DESC
```
