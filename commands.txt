1. How many active Agency agents are there?

2. How many active PD firms are there?

Count distinct INTAGTSEQ.

Previously verified: 2648.

3. How many Agency agents are there by region and distribution channel?

Use gold_agent_master.

Filter row_type = 'Agency'.

Group by region and agent_channel.

Count distinct INTAGTSEQ in each group.

Include all agent statuses because the question does not specify active agents.

The grouped counts should total 142857.

4. How many active Agency agents have at least one currently effective licence record?

Use gold_agent_master and gold_agent_license.

Select Agency agents with status 00 or 10.

Match using INTAGTSEQ and row_type.

A currently effective typed licence record must satisfy:

license_type IS NOT NULL
AND license_eff_date IS NOT NULL
AND license_exp_date IS NOT NULL
AND license_eff_date <= CURRENT_DATE()
AND license_exp_date >= CURRENT_DATE()

Prefer EXISTS to avoid multiplying agents through multiple licence records.

Count distinct Agency agents, not licence records.

Previously verified: 20400.

Explain that effective dates do not prove regulatory authorization.

5. How many Agency agents have education records?

Use gold_agent_master and gold_agent_education.

Match using INTAGTSEQ and restrict master.row_type to 'Agency'.

Prefer EXISTS or COUNT(DISTINCT education.INTAGTSEQ) to avoid duplicate agent counts.

Previously verified: 136467 Agency agents with education records.

6. How many active PD firms have no currently effective licence records?

Use gold_agent_master and gold_agent_license.

Filter active PD firms using codes 00 and 10.

Use NOT EXISTS with matching INTAGTSEQ and row_type = 'PD'.

Use the currently effective typed licence conditions from question 4.

Previously verified: 377.

Do not describe these firms as noncompliant. This query only checks the available licence records.

7. How many Agency agents are there by education level?

Use gold_agent_education and gold_agent_master.

Join on INTAGTSEQ and restrict master.row_type = 'Agency'.

Use the documented education mappings:

01 = College/University
02 = Vocational Education Institution
03 = Secondary School

Group by education level and count distinct agents within each level.

An agent can have multiple education levels, so group counts may overlap and should not be summed to calculate overall unique agents.

Handle NULL and unknown codes without inventing labels.
