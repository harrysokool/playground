# Data

This folder holds real receipt samples and is **not committed to Git** (see `.gitignore`)
because receipts may contain patient-identifiable information.

- `raw/` — input receipt images/PDFs to benchmark.

Place sample files directly in `raw/` before running the benchmark.

A `ground_truth/` folder for hand-annotated expected output will be added once accuracy
scoring is built (Phase 5), not before.
