A shorter roadmap:
1. Probability and statistics
   Expected value, variance, probability, correlation, regression.
2. Trading statistics
   Win rate, payoff ratio, expectancy, Sharpe ratio, drawdown.
3. Risk management
   Position sizing, portfolio risk, correlation, Kelly criterion, risk of ruin.
4. Market structure
   Bid, ask, liquidity, order books, market makers, options basics.
5. Poker and decision theory
   Expected value, incomplete information, Bayesian thinking, good decision versus good outcome.
6. Python for trading
   NumPy, pandas, scipy, matplotlib. Start testing trading ideas with real data.
7. Backtesting
   Overfitting, lookahead bias, survivorship bias, slippage, Monte Carlo testing.
8. Portfolio theory
   Diversification, covariance, factor exposure, portfolio volatility.
9. Machine learning
   Start with regression, trees, random forests, boosting.
10. PyTorch
    Learn it last, once your statistics and ML foundation is strong.
